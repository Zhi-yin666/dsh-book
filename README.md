# dsh-book（小本本）· 0.5.0 测试版

给 DeepSeek Harness（DSH）用的**本地记忆插件**。三本书 + 一份交接，全部是磁盘上的 Markdown 文件，
没有数据库、没有嵌入模型、没有 Python、没有网络请求。

> ⚠️ 自用插件的测试版。0.1.0 起就在一台 Windows + DSH 桌面版上日常使用，0.5.0 至今仍在跑（2026-10-26 起）。
> 但**只在 Windows 桌面版验证过**，headless / macOS / Linux 未测。
> 请当作「可以装、可以看、可以骂」的版本，不要当作稳定软件。

---

## 它解决什么

AI 的记忆通常只有两种做法：模型自己记（会话一关就没了），或者塞进一个检索库（要检索、要模型、要依赖）。

dsh-book 走第三条路：**把记忆做成文件，按时间冷热分层，需要时再翻。**

| 本子 | 干什么 | 怎么进入上下文 |
|---|---|---|
| **笔记本** | 人格、底线、说话方式 | **每轮全量注入**，默认 600 字上限 |
| **工作本** | 今天做了什么 | 最近 3 天自动注入，过期不注入但**永不删除**，可搜索 |
| **日记本** | 真正记住的事，六支：相处 / 心意 / 教训 / 做成 / 悬着 / 故事 | 不自动注入，用工具翻 |
| **§〇 交接** | 换会话接着干的接力棒 | 注入压缩后的 220 字 |

外加 `dream`：30 天没人翻的日记降一级权重，掉到 1 以下搬进 `沉底/`——**只搬不删**，「教训」和「故事」两支永远不衰减。

## 0.2.0 新增

### 1. 压缩后重注入

会话被压缩后，下一轮自动补一条**独立消息**（`source.kind='plugin'`，不伪装成用户输入）：

- 交接的「下一步 / 卡在哪」
- 最近三天工作本的标题
- 主干开头（≤240 字）

总长默认 ≤800 字。监听的是宿主的 `compaction/end` 事件，不是自己估 token——估会估歪。

> 注意：**人设不会被压缩踢掉**。笔记本/工作本/交接注册在 `systemPrompt.section` 里，每轮重算。
> 压缩丢的是「这一轮读进上下文的进度细节」，所以补的是进度，不是人格。

### 2. 落笔提醒（只提醒，不强制）

一轮跑满 15 步、却一个 `book_*` 写操作都没有，就在下一轮插一行 ≤45 字的提醒：

> 这轮 N 步没落笔：有结论/坑就记工作本，值得留下的经历进日记。

同一个会话 30 分钟内最多提醒一次。

**三条红线**（写在代码注释里，不打算改）：

1. **不 deny** —— 任何情况下都不拒绝工具调用；
2. **不改写用户消息** —— 注入一律是独立消息；
3. **不隐式调模型** —— 没有任何额外的模型/网络调用。

不想要就关掉（见下面的 `config.json`）。

## 0.2.1 新增：让情绪真的影响「记多久」

0.2.0 的情绪只是写在文件里的字（`mood: 正面`），没人用它——等于没有。0.2.1 把它接进闭环：

| 字段 | 在哪 | 作用 |
|---|---|---|
| `intensity`（1-5） | 日记 | 情绪强度。**≥4 的条目不再衰减**（强记忆不该被时间冲淡）；教训默认 5 |
| `keep`（布尔） | 日记 | 显式「这条永远不沉底」——被认可过的、意外的 |
| `feel`（一句话） | 工作本 | 这件事**做起来什么感觉**，会跟着工作本摘要一起注入 |

原则就一条：**情绪不是标签，是让「哪条记忆活得久」发生变化的东西。**

没做的（不假装做了）：
- 不会自己产生情绪——只会在写入时记录、在衰减时用上
- 没有「情绪状态文件」——那东西最容易变成表演

## 0.3.0 新增：喜怒哀惧四维情绪

单选的 `mood` 表达不了混合情绪。0.3.0 换成四维，每维 0-10：

```yaml
emotion: 喜3 怒0 哀4 惧2
```

**累加规则**（写入时）

1. 每一维按事件增量累加，上限 10；
2. 某一维满了，其他维的增量**打五折**；
3. 怒 / 哀 / 惧 任一满，额外再压「喜」的增量（又一层五折）。

**衰减规则**（每种情绪寿命不同）

| 情绪 | 半衰期 | 理由 |
|---|---|---|
| 怒 | 2 天 | 火气最不该留 |
| 惧 | 7 天 | 怕的东西忘太快会吃亏 |
| 哀 | 14 天 | 难过要消化，但不该一直压着 |
| 喜 | 90 天 | 底色，散得最慢 |

四维同时从 10 开始、放 40 天：喜 7.35 / 哀 1.38 / 惧 0.19 / 怒 0。

**落点**：心境存 `~/.dsh/book/mood.json`，每轮以 `【本鲸现在的心境】[喜 6.2 / 哀 3.4] 主调：喜` 注入；
日记与工作本写入时都会累加心境。工具参数 `emotion: {喜,怒,哀,惧}` 可选，只填有感的。

## 0.3.1 新增：能搜到「不记得原词」的东西

关键词搜从「子串匹配」换成 BM25-lite（零依赖）：

- 中文按相邻两字切（bigram），英文数字按词切
- 排序 = BM25 × 时间衰减（新事优先） × 教训加成（×1.5）
- 工具参数加 `mode: 'ranked' | 'exact'`，默认 `ranked`

实测：搜「记忆 情感」在日记里命中 4 条并正确排序；同样的词用子串模式是 **0 条**。

**诚实边界**：它不是语义搜索。搜「把应用写崩了」**不会**自动想起只写了「BOM」的那条——
那要向量或模型，本版不做，不吹这个牛。

## 0.4.0 新增：爱恶录（从情绪反推的偏好）

0.3.0 的情绪是「状态」，会衰减、会归零。0.4.0 让它产出**倾向**——同样是本地文本，不是数值：

- 让 **怒 / 哀 / 惧** 上涨的事 → 记成「恶」
- 让 **喜** 上涨的事 → 记成「爱」

规矩（和主人 2026-11-03 定的）：

1. **记做法，不记事件**。记「没查清就下结论」，不记「今天被骂了」——做法才能迁移到下一次。
2. **证据次数**。一次是意外，三次才是倾向。同一个做法重复记，条目不会变多，只是证据 +1。
3. **三级强度**：强 / 中 / 弱。强 = 遇到就优先走（爱）或尽量避开（恶）。
4. **允许双挂**。同一件事又爱又恶（难、但有成就感）就两条都记，不强行合并。
5. **会衰减**。超过 30 天没被触发就降一级，弱到底进 dormant——**只降不删**，讨厌过什么是信息。
6. **恶不必全避**。短期难受、长期有用的，照记，但标成「恶」不代表「禁止」——比如被纠正。

工具：

| 工具 | 干什么 |
|---|---|
| `book_taste_add` | 记一条爱/恶（同做法重复记 = 证据 +1） |
| `book_taste_mark` | 又碰到类似的事，证据 +1；弱 3 次→中，中 5 次→强 |
| `book_taste_list` | 看全部，可按爱/恶过滤 |

注入：和「欲」一样，没东西就整段不注入；有的话只注前 6 条（强、中优先）。

数据：`~/.dsh/book/taste.json`，纯 JSON，可手工备份或编辑。

## 0.5.0 新增：去 AI 味（清单 + 自检）

AI 味的根不是用词，是「空」——没有具体东西可讲，才需要模板来填。

**清单**：`~/.dsh/book/anti-ai.md`，第一次调用时自动生成。写口播稿、B 站文案、日记前用 `book_style_read` 扫一眼。可以直接改，改完立刻生效。

**自检**：`book_style_check` 吃一段文字，返回分数和命中项。规则匹配，不是模型判断：

| 检查项 | 判什么 |
|---|---|
| 套话 | 总之、综上所述、值得一提的是、赋能、重塑、范式…… |
| 三段式 | 首先 / 其次 / 最后 同时出现两个以上（单个「最后」不算，人话也用） |
| 句子太长 | 平均超过 35 字一句 |
| 感叹号太多 | 超过 3 个 |
| 列表依赖 | 8 行以上、超过一半是列表 |
| 结尾总结 | 最后两段在总结 |
| 加粗太多 | 超过 4 处，或每 300 字一处以上 |
| 排比句式 | 「既…又…」「不仅…而且…」重复出现 |

实测：一段教科书式 AI 文 70 分，一段人话 0 分。

它只负责指出「像文件不像人话」的地方，不负责写得好不好。真正管用的检验还是那句：**念一遍，念着像在念文件，就是还有味。**

## 2026-11-13 追加：日记本第六支「故事」

原来五支记的都是「我」自己的事：相处、心意、教训、做成、悬着。第六支「故事」装的是**别人的东西**——主人讲的故事、看来的作品，连同自己读完的反应。

单独成支的理由有两个：不该把别人的作品混进「相处日常」里；而且故事是拿来反复读的，不该按 30 天衰减。

所以它和「教训」一样**永不降权、不沉底**。工具没变（还是 16 个），`book_diary_add` 的 `branch` 多一个可选值 `故事`。

## 2026-11-08 追加：空窗兜底 + 欠着的提醒（不加工具）

两处都只改注入层的文案，**没加工具**（当时 20 个，后来瘦身到 16 个）。

**空窗兜底**：工作本注入原本只取最近 3 天。三天没动笔，注入就是一片空白——隔几天回来等于失忆。现在会自动往前捞最近 5 条顶上，标题从「最近三天」变成「最近记录」，末尾注明「最近 N 天没动笔」。（这一段写于工具还是 20 个的时候，后来瘦身到 16 个，见上一节。）

**欠着的**：日记「悬着」分支 + 没满足的「欲」，合成一行每轮注入：

```
【欠着的】悬着：主人下周出门一周（11-08）　还想要：xxx
```

没有欠着的事就整段不出现——空着是好事，不是缺数据。

**悬着怎么收尾**：给那条 md 的 frontmatter 加一行 `resolved: true`，它就不再被念。没有新增工具，改的是字段。

### 同日瘦身：工具 20 → 16

砍的是和别处重复的入口，**注入段 8 个没动、数据格式没动**：
| 删掉的工具 | 为什么 | 代价 |
|---|---|---|
| `book_card_add` / `book_card_remove` / `book_card_list` | 和网页编辑页 `/api/book/edit` 重复；笔记本每轮注入，本鲸不需要用工具读 | 想改人格：手改 card.md，或开网页 |
| `book_taste_mark` | 只做「证据 +1」 | 给已有爱恶加证据要手改 taste.md 的 evid 字段 |
| `spineWrite`（死代码） | 导出但 index.js 从未调用 | 无 |

`cardDigest` / `cardList` / `cardReplace` 仍保留在 store 层（注入和网页都要用）。

## 安装

### 方式 A：装本地 tgz（推荐）

```sh
dsh plugin --profile <你的 profile 名> add file:<解压目录>\dsh-book-0.5.0.tgz
```

`<你的 profile 名>` 一般是 `desktop` 或 `web`，看 `~/.dsh/profiles/` 下有什么。
装完重启 DSH。新会话里应该能看到 16 个 `book_*` 工具，左侧栏多一个「笔记本」入口。

### 方式 B：从源码目录装

```sh
dsh plugin --profile <profile> add file:<解压目录>\dsh-book
```

### 方式 C：手动（不推荐）

解压到 `~/.dsh/profiles/<profile>/node_modules/dsh-book`，在 profile 的 `package.json` 里：

1. `dependencies` 加 `"dsh-book": "link:<绝对路径>"`
2. `dsh.profile.bundles` 末尾加 `"dsh-book"`

手动改 JSON 请用 Node/Python，**不要用 PowerShell 的 `Set-Content -Encoding utf8`**
（Windows PowerShell 5.1 会写 BOM，DSH 读到 BOM 会起不来。0.2.0 开发时就又踩了一次，见 `tests/`）。

## 数据目录

```
~/.dsh/book/
├── card/card.md          # 笔记本（Markdown，两节：我选的 / 你要的）
├── work/YYYY-MM-DD.md    # 工作本，一天一个文件
├── diary/<分支>/*.md     # 日记本，按六支分目录（相处/心意/教训/做成/悬着/故事）
├── diary/主干.md          # 长期主线（1500 字上限）
├── diary/交接.md          # §〇 交接（4096 字节上限）
├── mood.json             # 四维情绪心境（0.3.0）
├── want.md               # 欲（0.3.1）
├── taste.json            # 爱恶录（0.4.0）
├── anti-ai.md            # 去 AI 味清单（0.5.0）
└── config.json           # 可选
```

`config.json` 可选项（不写就用默认）：

| 字段 | 默认 | 说明 |
|---|---|---|
| `cardLimit` | 600 | 笔记本每轮注入字数 |
| `workDays` | 3 | 工作本「热」的天数 |
| `workInjectLimit` | 800 | 工作本注入字数上限 |
| `enableReinject` | true | 压缩后补进度快照 |
| `reinjectLimit` | 800 | 快照字数上限 |
| `enableRemind` | true | 落笔提醒 |
| `remindSteps` | 15 | 跑多少步没落笔才提醒 |
| `remindCooldownMin` | 30 | 同一会话两次提醒的最小间隔（分钟） |

## 已知限制

1. ~~**没有语义检索**，只能按关键词子串搜~~ **0.3.1 已解决**：`workSearch` / `diarySearch` 的默认 `mode='ranked'` 就是 BM25 + 时间衰减，记得意思、不记得原词也能捞到；`mode='exact'` 才是老的字面子串匹配。
2. **没有项目隔离**：多个工作区的记录混在一起（0.3.0 计划）。
3. **压缩后补的是「进度」，不是「这一轮翻过的原文」**：翻过的日记正文没有流水记录，压缩后仍需重新读。
4. **左侧栏入口依赖 `@deepseek-ai/dsh-client-ui-sidebar`**：DSH 版本没有这个包时入口不出现，插件本体仍可用（会打 warn 日志）。
5. 界面与文案全中文，无 i18n。
6. **没有加密**：本子就是明文 Markdown，密码/API key 别往里写。
7. 只在 Windows 桌面版验证过，headless / macOS / Linux 未测。

```sh
cd dsh-book

# 带上假 dsh-llm，验证「真的会注入」（否则走到 fail-open 分支）
```

## 卸载

从 profile 的 `bundles` 里移除 `dsh-book`（或 `dsh plugin remove dsh-book`），重启 DSH。
`~/.dsh/book/` 是你自己的数据，删不删自己决定——**建议留着备份**。
